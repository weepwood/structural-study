BLUEPRINT SYSTEM

00 设计原则

这套系统服务于一个明确目标：让交互式结构图看起来像 1:1 的机械制图，同时保持单文件、零依赖、可离线。动画与交互只允许让图纸「活起来」，不允许改变制图语言。

01 / 正投影，不透视相机不做透视除法，线宽不随深度变化。立体感来自姿态旋转与视差，而不是近大远小。
02 / 信息分层靠线型可见实线、隐藏虚线、中心线点划线，三种线型承担三种信息层级；颜色只做点睛。
03 / 纸先于屏幕底色是纸、有网格、图框、裁切角标、印章与标题栏；禁止渐变、发光、玻璃拟态与圆角大卡片。
04 / 令牌即契约所有数值集中在 tokens.json，三主题结构相同仅换值；改色先改令牌，再重新生成。
05 / 零依赖可离线系统等宽字栈、无外部字体 / 图标 / CDN；成品与本文档页都能直接用 file:// 打开。
06 / 可测量、可退化每件零件有编号与尺寸；无 JS / 无 Canvas / reduced-motion / 后台标签页均有明确降级路径。

01 色彩系统

十个语义角色，三套取值。点击任意色值即可复制。强调色只用于小面积：印章、剖切、选中、实时读数、角标、滑块拇指；绝不铺满整块区域。

对比度 / WCAG 2.1

02 排版系统

只使用系统等宽字栈，不加载 webfont。图纸内全部英文大写，小字号靠字距建立秩序；Canvas 文字由 spaced() 逐字符绘制并缓存字宽，不依赖浏览器 letterSpacing。

字距与格式约定

CANVAS WIDE ORTHOGRAPHIC
CANVAS NORMAL SHEET 01 / 01
CANVAS TIGHT DATUM ±0.00
PANEL HEAD CONTROL / 控制台

03 线型与图层

线型是这套系统最重要的信息编码。统一 lineCap='butt'、lineJoin='round'，不用阴影与渐变；globalAlpha 仅印章与十字准星可用。

每帧绘制顺序

实体遮挡不是靠深度缓冲：环带以 fill('evenodd') 填入 --surface，按中心 z 排序后由近及远覆盖，近处环带会擦掉后方线条。X-RAY 关闭该步即可看穿内部。

05 空间与布局

24px 细网格 + 120px 主网格构成纸面；16px 内缩图框；右下控制台固定 252px（窄屏 210px）；结构随视口等比缩放，标注保持固定像素字号。

24px GRID / 120px MAJOR
响应式：DPR = min(2, devicePixelRatio)；baseScale = min(W/(W<720?640:1060), H/700)；中心 cx=W/2、cy = W<720 ? H*0.42 : H/2-6。窄屏把右侧标签上移并限制 cap = H*0.52，避免与控制台重叠。

06 交互与动效

所有手感参数集中在 CFG，改动一处即可调校。入场动画使用墙钟进度与帧计数进度取大值，后台标签页或无头渲染都不会卡在半途。

状态与入口

  • 指针：拖拽旋转（带惯性）、鼠标视差、滚轮拆解、Shift+滚轮缩放、点击拾取线段。
  • 键盘：T 主题 / R 重置 / F 随机姿态 / S PNG / H 隐藏线 / G 网格 / 空格暂停。
  • URL：theme explode section zoom yaw pitch part xray auto intro，用于分享视图与自动化截图。
  • 降级：prefers-reduced-motion 关闭自转与入场；document.hidden 停绘；无 JS / 无 Canvas 2D 时显示静态提示。

08 使用与维护

三种消费方式

  1. 直接用成品：../index.html 是单文件零依赖，双击即可运行，所有令牌已内联。
  2. 做自己的图纸：用 orthographic-blueprint 技能包从模板生成，令牌值随模板一起带上。
  3. 做配套页面：引入独立样式表，主题用 data-theme 切换：
<link rel="stylesheet" href="design-system/tokens.css">
<html data-theme="cyan"> … </html>

/* CSS */
.panel { background: var(--panel); border: 1px solid var(--line); }
.accent { color: var(--accent); }
svg line { stroke-width: calc(var(--lw-bold) * 1px); }

改一个颜色 token 的正确流程

# 1. 只改唯一事实来源
vim design-system/tokens.json

# 2. 重新生成 tokens.css 与本页面内的生成块
npm run tokens

# 3. 校验（含生成物一致性检查），通过后提交
npm run verify
git push origin main        # Pages 自动重新部署
分层关系：design.md 是项目级设计系统总纲；design-system/tokens.json 是机器可读的唯一数值源；tokens.css 与本页面内两个生成块是产物；技能包 references/design-language.md 是同一套风格的可携带版规范。四者数值必须一致，由 verify.mjs 守门。
