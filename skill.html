01 它能做什么

说出「用这种工程图纸风格做一个 X」，技能会引导生成一张可交互的正交制图：把主体拆成带编号与规格的零件，用 Canvas 2D 手绘全部线条，产出一个 零依赖、可离线、可分享 URL 状态 的 HTML 文件。

视觉契约正交投影无透视除法；可见实线 / 隐藏虚线 / 中心线点划线；纸色擦除做实体遮挡。
图纸语义零件编号、尺寸公差、比例、投影方式、实时坐标与角度、剖切标记、标题栏与图号。
交互机制拖拽惯性、鼠标视差、滚轮拆解、Shift 缩放、点击拾取、爆炸与剖切、三主题切换。
工程质量单文件零请求、reduced-motion、后台停绘、Canvas 降级、PNG 导出、调试 API、自检脚本。

02 安装

方式 A — 解压即用（用户级，跨项目可用）：下载 ZIP，解压到 ~/.workbuddy/skills/orthographic-blueprint/，重新加载技能即可。

方式 B — 项目级：把整个目录复制进项目的 .workbuddy/skills/，随仓库共享给协作者。

方式 C — 脚本安装：在本仓库克隆后运行

node skills/orthographic-blueprint/scripts/install.mjs                 # 用户级
node skills/orthographic-blueprint/scripts/install.mjs --project .      # 项目级
node skills/orthographic-blueprint/scripts/install.mjs --force         # 覆盖已有安装
安装脚本与自检脚本都只用 Node 内置模块，不需要 npm install。技能清单含 agent_created: true，可被后续编辑与管理。

03 使用流程

  1. 确定主体与 3–6 个零件的编号、几何参数、规格文本。
  2. 用 scaffold.mjs 从模板生成新 HTML，替换标题与图号。
  3. 改 PARTS 与 buildPart()（模板中标有 // REPLACE: GEOMETRY），其余绘制层保持不动。
  4. 运行 check-drawing.mjs 自检，再用无头浏览器截取默认 / 深色 / 爆炸三态核对布局。
  5. 交付单文件，附带可分享的 URL 状态，例如 ?theme=cyan&explode=45&part=R-03。
node skills/orthographic-blueprint/scripts/scaffold.mjs \
  --out ./drawing.html --title "STRUCTURE 02" --subject "TRUSS ASSEMBLY" --code 02

node skills/orthographic-blueprint/scripts/check-drawing.mjs ./drawing.html
