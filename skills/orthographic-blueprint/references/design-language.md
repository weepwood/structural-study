# 视觉规范 — 正交工程制图纸

本文件是风格的唯一数值来源。定制模板时按此处取值，不要凭感觉调色或改线宽。示例项目：`structural-study/index.html`。

## 1. 设计定位

一张摊开在桌面上的**工程图纸**，而不是一块屏幕 UI。观者应感觉在看 1:1 的机械制图：纸有底色、有网格、有图框、有裁切角标、有印章、有标题栏；结构以墨线绘制，标注用等宽字距拉开的小号字；交互只是让图纸「活起来」，不改变制图语言。

关键词：克制、单色、精确、可测量、无光影、无立体材质。

## 2. 配色（三主题，CSS 变量）

| 变量 | 用途 | PAPER 米白 | INK 墨黑 | CYANOTYPE 蓝晒 |
|---|---|---|---|---|
| `--bg` | 纸面 / 擦除底色 | `#f0ebe4` | `#171512` | `#0f2b52` |
| `--ink` | 主结构实线、正文 | `#211e1a` | `#e9e3d8` | `#e2edf8` |
| `--surface` | 实体环带填充 | `#ece6de` | `#1e1b17` | `#14325e` |
| `--faint` | 极淡辅助线、辅助刻度 | `rgba(33,30,26,.13)` | `rgba(233,227,216,.14)` | `rgba(226,237,248,.16)` |
| `--grid` | 24px 细网格 | `rgba(33,30,26,.055)` | `rgba(233,227,216,.06)` | `rgba(226,237,248,.075)` |
| `--hidden` | 隐藏虚线 | `rgba(33,30,26,.30)` | `rgba(233,227,216,.28)` | `rgba(226,237,248,.32)` |
| `--accent` | 强调：印章、剖切、选中、读数、引导线 | `#b23d22` | `#e87048` | `#ffcb63` |
| `--panel` | 控制台半透明底 | `rgba(240,235,228,.94)` | `rgba(23,21,18,.94)` | `rgba(15,43,82,.95)` |
| `--line` | 图框、分隔线、尺寸线 | `rgba(33,30,26,.30)` | `rgba(233,227,216,.30)` | `rgba(226,237,248,.32)` |
| `--soft` | 次级文字、引线 | `rgba(33,30,26,.55)` | `rgba(233,227,216,.58)` | `rgba(226,237,248,.62)` |

规则：

- 强调色只用于小面积（印章描边、剖切线、选中零件、实时读数、角标、滑块拇指），**绝不大面积铺色**。
- 纸面不是纯白，墨色不是纯黑；保留低对比的暖/冷灰度层次。
- 三主题必须结构相同、仅变量换值；`meta[name=theme-color]` 随 `--bg` 更新。
- 字体只用系统等宽栈：`ui-monospace, SFMono-Regular, Menlo, Consolas, "Liberation Mono", monospace`。不加载 webfont。

## 3. 线型与线宽（Canvas 2D，CSS 像素）

| 层级 | 颜色 | 线宽 | 虚线 | 用途 |
|---|---|---|---|---|
| 主轮廓 `bold` | `--ink`（选中用 `--accent`） | 1.55 / 选中 2.0 | 无 | 外轮廓、球体大圆 |
| 可见结构 `solid` | `--ink` | 1.05 / 选中 1.45 | 无 | 可见内轮廓、刻度、经纬线 |
| 隐藏结构 `hidden` | `--hidden`（选中 `--accent`） | 0.85 | `[4,4]` | 被实体遮住的轮廓 |
| 辅助 `faint` | `--faint` | 0.8 | 无 | 厚度侧边、背面刻度、地面剖面线 |
| 中心线 / 装配引导 | `--faint` / `--accent` | 0.8–1.0 | `[12,4,2,4]` / `[9,4,2,4]` | 轴线、爆炸回位线、剖切扫描线 |
| 图框 | `--line` | 1.0 | 无 | 16px 内缩矩形 |
| 裁切角标 | `--accent` | 1.2 | 无 | 四角 L 形短线 |
| 尺寸线 | `--line` | 0.9 | 无 | 带实心三角箭头 |
| 引线 | `--soft`（选中 `--accent`） | 0.8 | 无 | 三段折线 + 端点双圆点 |

统一 `lineCap='butt'`、`lineJoin='round'`，不用 `shadowBlur`、不用渐变、不用 `globalAlpha` 做立体感（仅印章与十字准星允许 `globalAlpha` 0.55–0.75）。

## 4. 图层绘制顺序（每帧）

1. `drawPaper()`：填满 `--bg`；24px 细网格（`--grid`）+ 120px 主网格（`--faint`）；16px 图框；四角裁切角标；页眉 `STRUCTURE NN / SUBJECT` 与右对齐 `ORTHOGRAPHIC STUDY · SHEET 01 / 01`；页眉下 1px 分隔线；右上角微微倾斜的 `ORIGINAL` 印章框。
2. `drawAxes()`：两条点划线中心轴；基准地面线 + 每 13px 一条 45° 剖面短斜线；`DATUM ±0.00`。
3. 结构线稿：按零件中心 z 排序，逐个 `drawPrim()` —— 先 `fill('evenodd')` 纸色实体，再 hidden → faint → solid → bold → 节点小方块 → 刻度数字 → 爆炸引导线。
4. `drawSection()`：水平点划线扫描、与本帧线段求交、去重标记交点、`SECTION A-A` 标签 + 两端 `A`。
5. `drawLeaders()`、`drawDimensions()`、`drawHUD()`：引线编号、尺寸线、角度扇形、左上实时读数、鼠标十字准星、左下标题栏。
6. DOM 控制台（浏览器合成层，永远在最上）。

## 5. 标注与排版

- **字距**：用 `spaced()` 逐字符绘制，字距 `sp` 取 0.7–1.4；不要用 `letterSpacing` 属性依赖浏览器实现。
- **字号**：页眉 12 / 9，印章 9，读数 10 / 9，尺寸 10，引线主行 9.5、副行 8.5，标题栏 10 / 8.5。全部小号字，靠字距和大写建立秩序。
- **格式**：全大写英文 + 数字，编号 `R-01`，尺寸 `Ø 480.00 ±0.05`，高度 `H 480.00`，角度 `YAW θ -35.5°`，坐标 `X 0480  Y 0210`（补零到 4 位），比例 `SCALE 1:1.00`，状态 `STATE ASSEMBLED / EXPLODED 45%`。
- **标签避让**：先用 `--bg` 擦出标签底板再画引线，保证引线不穿过文字；同侧标签按 y 排序、最小间距 50px，超出下边界时整组上移；桌面端右侧标签收在 `W-300`（控制台左缘），避免被面板遮住。
- **角度指示**：画扇形（从圆心到弧两端闭合 + 淡填充 `globalAlpha=.075`），不要画整圆；负角用 `anticlockwise=true`。
- **标题栏**：246×72，三行两列分隔，`GIMBAL ASSEMBLY / 01`、`1ST ANGLE`、比例、图号、日期；底色先用 `--bg` 覆盖网格。

## 6. 交互与动效数值（`CFG`）

| 参数 | 值 | 含义 |
|---|---|---|
| `followYaw` / `followPitch` | `.16` / `.11` | 鼠标视差最大弧度 |
| `parallaxEase` | `.06` | 视差缓动 |
| `dragSpeed` | `.006` | 拖拽弧度/像素 |
| `inertia` | `.93` | 松手速度衰减 |
| `autoSpin` | `.0016` | 自动自转角/毫秒系数 |
| `introMs` / `introFrames` | `1900` / `100` | 装配合拢动画的墙钟/帧计数双进度 |
| `wheelExplode` / `wheelZoom` | `.0006` / `.0008` | 滚轮灵敏度 |
| `pickRadius` | `13` | 点击拾取半径 |

入场动画：零件从爆炸位逐层合拢、依次显影；`alpha` 按索引错开 0.13。**必须用 `Date.now()` 墙钟进度与帧计数进度取大值**，避免后台标签页或无头渲染卡在半途只剩淡线。

交互清单：拖拽旋转（带惯性）、鼠标移动视差、滚轮拆解、Shift+滚轮缩放、点击拾取零件、键盘 `T` 主题 / `R` 重置 / `F` 随机姿态 / `S` PNG / `H` 隐藏线 / `G` 网格 / 空格 暂停、控制台四个滑块与六个开关。

URL 状态：`theme` `explode` `section` `zoom` `yaw` `pitch` `part` `xray` `auto` `intro`，用于分享视角与自动化截图（`?intro=0&auto=0` 跳过动画与自转）。

## 7. 控制台（DOM）

右下 22px、宽 252px、1px `--line` 边框、`--panel` 半透明底 + `backdrop-filter: blur(9px)`、无圆角、`box-shadow: 0 10px 34px rgba(0,0,0,.09)`。标题 `CONTROL / 控制台` 带折叠按钮；滑块轨道 2px、9×9 方形拇指用 `--accent`；开关为 1px 方框按钮，激活态描边与文字转 `--accent`、底色 `color-mix(in srgb, var(--accent) 8%, transparent)`；底部规格卡显示零件 ID、名称与 6 条规格。移动端宽 210px 并避让 `env(safe-area-inset-*)`。

## 8. 响应式、可访问性、性能

- `resize()`：`DPR = min(2, devicePixelRatio)`，`setTransform(DPR,...)`；`baseS = min(W/(W<720?640:1060), H/700)`；中心 `cx=W/2`、`cy = W<720 ? H*0.42 : H/2-6`。
- 结构整体随视口缩放，标注用固定像素字号；窄屏时右侧标签与控制台冲突，需要把标签上移并限制 `cap = H*0.52`。
- `<canvas role="img" aria-label="...">`、`<noscript>`、无 Canvas 2D 时的静态降级提示、`:focus-visible` 描边。
- `prefers-reduced-motion` 关闭自转与入场；`document.hidden` 时跳过绘制；`spaced()` 字宽用 `Map` 缓存，避免每帧数百次 `measureText`。

## 9. 反模式清单

| 不要 | 原因 |
|---|---|
| 透视相机、按 z 缩放线宽 | 破坏制图的「正投影」语义，变成 3D 渲染 |
| `wireframe: true` / Three.js `EdgesGeometry` 直出 | 线太密、无可见/隐藏区分，失去图纸信息层级 |
| 渐变、投影、发光、玻璃拟态、圆角大卡片 | 与纸面印刷质感冲突 |
| 纯白 `#fff` / 纯黑 `#000` / 高饱和霓虹 | 失去暖灰/蓝晒的纸张层次 |
| 大面积强调色、彩色填充实体 | 强调色只允许点睛 |
| 无编号无尺寸的「线框球」 | 只是线框图，不是工程图 |
| 外部字体、图标库、CDN | 破坏零依赖与离线可运行 |
| 标签直接压在线上、引线穿过文字 | 工程图最忌阅读干扰 |
